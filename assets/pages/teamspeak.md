## Installing TeamSpeak

Before installing TeamSpeak you have a choice to make, TeamSpeak offers 2 different clients. The main difference between them is 3 has an old interface but you are not required to sign up for a TeamSpeak account. While 6 has a newer interface but requires a free TeamSpeak account.

On the TeamSpeak [**DOWNLOAD** page](https://teamspeak.com/en/downloads?product=ts3) you can select your preferred TeamSpeak client by clicking TeamSpeak 3 or TeamSpeak 6 button as shown in the screenshot below

## TeamSpeak 3 guide

When installing TeamSpeak 3 it will ask you if you want to install the optional software called overwolf, you do not need this so it is recommended to uncheck the checkbox marked with red as shown in the screenshot below.

![The TeamSpeak 3 installer with the Overwolf checkbox marked in red]({{ '/img/ts3_overwolf.png' | relative_url }})

After opening TeamSpeak it will ask you if you want to create an account but you do not have to if you'd prefer not to. Click continue without logging in or make an account

![The TeamSpeak 3 login window with the continue without logging in option]({{ '/img/ts3_account.png' | relative_url }})

### Joining the server

Click on the Bookmarks button and then Manage Bookmarks

![The Bookmarks menu with Manage Bookmarks highlighted]({{ '/img/ts3_bookmark1.png' | relative_url }})

The only important field is the *Server Nickname or Address*
which should be `donkey.beauty`
For nickname set it to your in-game username, the bookmark name is just how you will see it in your own bookmark list.
Leave the password field empty

![The bookmark editor with donkey.beauty filled in as the server address]({{ '/img/ts3_bookmark2.png' | relative_url }})

Now that you've saved the bookmark it will always show up in your bookmarks list as shown below.
Simply click the bookmark and it will connect you to the server!

Once you are connected to the TeamSpeak server, send your nickname in the in-game guild chat and say that you are requesting access to the server and someone will give you the appropriate permissions to access the rest of the server.

![The bookmarks list with the new donkey.beauty bookmark]({{ '/img/ts3_connect_bookmark.png' | relative_url }})

When you have access to the rest of the server you can join any of the existing Squadron channels or if there are no Squadron channels currently, Then as seen in the screenshot below in the red box indicated with "1". You can simply join this channel and the bot will automatically create a new squad channel.
This will make you the channel admin for that temporary squad channel so you can change its name, description and permissions if you'd like to do so.

Joining the channel indicated with the green box in the screenshot will create a private channel locked by a password, the bot will send you a private message with the password of that channel.

![The squad channels, with the create-new-squad channel marked red and a squadron channel marked green]({{ '/img/ts3_channel1.png' | relative_url }})

## TeamSpeak 6

After installing, the first time you launch the program TeamSpeak will ask you to back up your recovery key, if you forget your password you'll need this key to get your TeamSpeak identity back.
In order to proceed click the checkbox and hit continue.

![The recovery key backup dialog with the confirmation checkbox]({{ '/img/ts6_recoverykey.png' | relative_url }})

Pretty self explanatory, choose a dark or light theme for TeamSpeak

![The theme chooser with the dark and light options]({{ '/img/ts6_theme.png' | relative_url }})

First click the plus to add a new bookmark,
Then type in `donkey.beauty` as the bookmark address.

![The TeamSpeak 6 bookmark editor with the plus button and address field]({{ '/img/ts6_bookmark1.png' | relative_url }})

OPTIONALLY you can right click your newly created bookmark and change its display name to something memorable.

After joining the TeamSpeak server, send your nickname in the in-game guild chat and ask for someone to give you access to the rest of the TeamSpeak server and someone will give you the appropriate permissions.

![The bookmark saved and connected to the server]({{ '/img/ts6_bookmark2.png' | relative_url }})

Now that you have your correct permissions you can join any of the currently existing Squadron channels for example as shown in the screenshot highlighted in green "Squadron Alpha"

If there are no squadron channels currently available you can create one by joining one of the channels highlighted in red like the "Create new squad" channel.

![The TeamSpeak 6 channel tree with Squadron Alpha marked green and the create-new-squad channels marked red]({{ '/img/ts6_channel1.png' | relative_url }})
